What you can build

pgstream enables real-time data pipelines for modern applications.

Cache Invalidation

Automatically invalidate Redis or Memcached entries as soon as database records change. No more stale cache or complex dual-write logic.

Real-time Analytics

Stream database changes to Elasticsearch, ClickHouse, or data warehouses for live dashboards without batch ETL jobs.

Data Synchronization

Keep microservices in sync by streaming changes across service boundaries. Each service gets its own read-optimized view.

Audit Logs

Capture every INSERT, UPDATE, and DELETE as an immutable event stream for compliance, auditing, and change tracking.

Search Index Updates

Keep search indexes in sync with your database in real-time, not on a cron schedule.

CQRS & Event Sourcing

Feed read models and event stores directly from your PostgreSQL write model.

Why pgstream?

Built for production workloads.

✓

Zero Data Loss

LSN tracking and replication slots ensure every change is captured, even through restarts.

✓

Lightweight

Single Go binary. No Kafka Connect, no ZooKeeper, no JVM.

✓

Native PostgreSQL

Uses pgoutput logical decoding — the same mechanism as Debezium, without the infrastructure.

✓

Testable

Interface-driven design with mockable connectors. Unit-test without a real database.

✓

Graceful Shutdown

Handles SIGTERM properly, flushing buffers and closing connections cleanly.

✓

Docker & CI/CD Ready

Multi-stage builds, GitHub Actions, one-line Docker deploy.

How it works

Simple architecture that plugs into your PostgreSQL instance.
